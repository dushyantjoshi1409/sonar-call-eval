The four core checks

Keep every failure explainable.

C1 / Listening

Meaning respected?

Entities, negation and corrections. Reply mismatch is a listening proxy.

C2 / Repetition

Unnecessary loops?

Separate avoidable repeats from requested clarification or readback.

C3 / Flow + capture

Right follow-up?

Receipt first, then positive or negative feedback. Preserve the actual issue.

C4 / Length

Too long per turn?

Counts plus timing precision. Proposed initial flags: over 60 words or 20 seconds.

The handwritten length rule omits “not”. Avoiding excessive length is an explicit interpretation, not a literal supplied instruction.
